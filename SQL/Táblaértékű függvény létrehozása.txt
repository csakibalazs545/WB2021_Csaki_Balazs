A következő utasításpélda egy táblázat értékű függvényt hoz létre, amely egy terméklistát ad vissza, amely tartalmazza a termék nevét, modellévét és egy adott modellév listaárát:

CREATE FUNCTION udfProductInYear (
    @model_year INT
)
RETURNS TABLE
AS
RETURN
    SELECT 
        product_name,
        model_year,
        list_price
    FROM
        production.products
    WHERE
        model_year = @model_year;

A szintaxis hasonló ahhoz, amelyik egy felhasználó által definiált függvényt hoz létre.
